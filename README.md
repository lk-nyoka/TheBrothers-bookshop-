# 📚 The Brothers Bookshop

A multi-page e-commerce website for a student bookshop selling new and second-hand university textbooks (medicine, engineering and commerce). This was my first web development project (2024).

## Pages

- **Home** — hero banner, featured products, deals and textbook categories
- **Shop** — product grid across two pages, with individual product pages
- **Cart** — shopping cart layout with totals
- **Blog, About, Contact** — content pages with a contact form
- **Sign up** — registration form backed by a small PHP handler

## Tech stack

HTML · CSS · JavaScript · PHP

## Run locally

Open `index.html` in a browser. The sign-up form (`signup.php`) needs a PHP server, for example:

```bash
php -S localhost:8000
```
